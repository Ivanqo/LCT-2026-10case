## Покрытие замеров

Пакеты для возмущений: NOV, ALT79B, TYU; число файлов источников: 3 пакета, выбранных как NOV и два небольших пакета корпуса. Ещё 32 synthetic variants запускались на NOV. Профиль крупнейшего пакета (Полярная 25) завершён за 723,75 с при пике RSS 2 292 776 960 байт. Все команды harness выполнялись последовательно, каждая CLI-команда ограничена 1500 секундами.

## Ограничения замеров

- Не измерены корпусный recall и полный список мутаций из задачи. Всего проверено 68 вариантов: 36 на трёх источниках и 32 дополнительных на NOV; не был выполнен полный перебор 47 генераторов harness.
- Имена каталогов длиннее `NAME_MAX` проверены через симуляцию ошибки сканирования на Windows; реальный Linux `ENAMETOOLONG` на целевой файловой системе здесь не воспроизведён.
- OCR ограничен таймаутом на страницах, но универсальный жёсткий таймаут для каждого вызова PDF-парсера не реализован; общий CLI-run в harness останавливается по лимиту 1500 секунд. Долгий вызов парсера остаётся риском.
- Пик RSS harness снимается каждые 0,5 с и суммирует RSS процессов; общие страницы памяти могут быть посчитаны повторно, а короткий пик между отсчётами может быть пропущен.
- Указанный пользовательский venv сообщает Python 3.12.1; в исходном контексте указан Python 3.11. Все тесты и прогоны используют предоставленный venv.
- Изменения образа и зависимостей не требуются; файлы Docker/compose не менялись.
