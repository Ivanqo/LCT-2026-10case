## 3. Дисковый кэш

`page_quality_cache.py`: ключ = SHA-256 файла + номер страницы + `QUALITY_ALGORITHM_VERSION = "page-quality-v2"` (константа в коде; менять при любом изменении решающей логики) + `OCR_ENGINE` + `OCR_LANG` + версия PyMuPDF. Каталог: `CASE10_QUALITY_CACHE_DIR`, иначе `$CASE10_LIVE_TAGGER_CACHE_DIR/quality`, иначе кэша нет (как у кэша экспликаций). Запись атомарная (tmp + `os.replace`), ошибка записи — предупреждение в лог; чтение: битый/чужой/не тот ключ/не тот sha — промах. Не кэшируются результаты с `*_OCR_UNAVAILABLE` и `PAGE_QUALITY_READ_FAILED:*`. Тесты: холодный и тёплый результаты равны (в т.ч. `json.dumps`), тёплый не читает PDF, битые файлы, недоступный каталог, ключ зависит от движка/языка/версии.

## 5. Открытые риски

1. Штамп-аннотации: в реальной выборке только 2 страницы (обе без флага, решения совпали); основное покрытие — синтетические PDF. Реальных штампов на русских листах с текстом под ними не нашлось.
2. Различия, которые старый алгоритм имел «случайно» и которые новый не воспроизводит: (а) по коду старый падал в `PAGE_QUALITY_READ_FAILED:*` на странице, где `Pixmap(xref)` не создаётся, новый такую страницу оценивает по геометрии; (б) старый не видел картинку, чей Pixmap-digest не совпал с digest в `get_image_info`. Ни одного такого случая в 460 страницах не было, но поток 8 124 страниц целиком не прогонялся.
3. Картинки с `xref == 0` (inline) исключены намеренно — старый алгоритм их не видел (только `get_images`).
4. Версия PyMuPDF в ключе кэша: после обновления библиотеки кэш пересчитается; проверено только на 1.24.2 (версия образа).
5. Под тяжёлые страницы (6 349 картинок) `get_image_info` сам занимает 1,5–2 с; это остаток, который кэш убирает.
6. Кэш качества не заменяет кэш тэггера: страницы с битым шрифтом при сломанном локальном Tesseract 3.02 (`ocr_page_tsv_invocation_failed`) не кэшируются нигде и пересчитываются при каждом запуске (теперь это быстро: ~0,1–0,5 с/страница).
7. Остаются медленными: этап тэггера на холодном кэше (не менялся), `get_text("words")` ~0,5 с на страницу с 1 600 слов, чтение/SHA-256 60-МБ PDF при смене документа. Группировка оценки страниц по документу устраняет перечитывание для фрагментов тэггера, но не для страниц, найденных только через rule-pack (`observation.document`).
8. DOO25 и посевы D не запускались (по условию). Эффект на DOO25 по аналогии ожидается, но не измерен.
