## 3. Общие правила

Все материалы организатора можно использовать для разработки (экспертная сессия, Q11); скрытый тест — другая документация (Q13). Запрещено:
- значения gold как lookup в inference-коде;
- имена файлов, страницы, диапазоны номеров, названия элементов и объектные константы в механизмах;
- выдача низконадёжного вывода как факта — вместо догадки `LOW_QUALITY` / `CLARIFICATION_REQUIRED`;
- внешние сервисы в рантайме.

Каждый вывод системы должен проверяться инспектором по первоисточнику за секунды.

**Практика агентов:**
- коммит только своих путей — `git commit -- <paths>`;
- Windows `write_text` пишет CRLF — патчить через `write_bytes`;
- Git Bash портит пути вида `/in` в контейнере — `MSYS_NO_PATHCONV=1`;
- Docker Desktop между сессиями останавливается;
- тяжёлые данные — на `E:\`.
