После замены кода рекомендуется полностью пересобрать проект:

1. docker compose down
2. docker compose up --build -d

Если в системе уже были старые индексы RAG/старые загруженные документы и нужно начать с чистого состояния:

1. docker compose down -v
2. docker compose up --build -d

Причина: в обновлении изменены пайплайны ingest/retrieval, структура ответа чата и настройки эмбеддингов для русского языка.
